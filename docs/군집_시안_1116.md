# 군집 시안 01 — 대표 병사와 열린 대열

기본 게임에는 적용하지 않은 선택형 시안이다. `Type2View.formation_preview` 기본값은 false.

- 한 부대를 대표 병사 14~28명으로 그린다. 보병은 넓은 대열, 원거리 계열은 여섯 열, 기병은 쐐기다. 기존 병종별 단일 인형 아틀라스를 재사용한다.
- 병사 수천 명의 중첩과 금빛 장식을 걷어내고 파랑/빨강으로 피아를 구분한다. 메달·군기·병력 표는 유지한다.
- 대표 대열은 기존 부대 위치·방향·발자국을 따르며 병력 감소에 따라 빈자리가 생긴다. 개별 병사 시뮬레이션의 공중 날리기를 표시하지 않는다. 시안에서는 BattleView의 평타·기술 blast 호출도 생략한다.
- 전투 엔진·편성·피해 수치·기본 화면은 변경하지 않는다. 대표 대열은 실제 병사 개별 충돌 위치와 일치하지 않는 시각화다. 정식 적용 전 전선 접촉·병력 감소·패주 표현을 더 다듬어야 한다.

실행:

```powershell
& tools/Godot_v4.4.1-stable_win64_console.exe --path solgukji_godot --resolution 540x960 res://tests/formation_preview.tscn
# 같은 편성/시드의 기존 화면
& tools/Godot_v4.4.1-stable_win64_console.exe --path solgukji_godot --resolution 540x960 res://tests/formation_preview.tscn -- --baseline
```

개전 0.5초와 교전 8초를 build/formation_0.png, formation_8.png에 저장한다. 비교는 baseline_0.png, baseline_8.png. Vulkan 실제 화면에서 시안 두 장을 확인했다. 교전 시 병사 밀도는 줄었지만 기술 이름·피해 숫자·위험 신호가 겹치는 문제는 남아 있다.
