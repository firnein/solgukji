# 특기 · 기술 개편 —— 조건 × 효과 (설계안, 2026-10-30)

사용자 결정: 계열(화공 · 수공 · 돌파 · 표적 · 철벽 · 계략 · 인덕)이 "상태를 건다 → 그 상태인 적을 더 친다 → 추가 피해 → 저항"으로 이름만 다른 같은 틀이라 재미가 없다.
→ **특기를 '언제(조건) + 무엇을(효과)'로 짠다.** 덱의 개성은 상태 이름이 아니라 '언제 터지는가'에서 나온다.
기술(액티브)은 카드당 1개 제한을 없애 여러 개를 든다. 인연(인물 조합) 시너지는 넣지 않는다.

---

## 1. 구조

| | 특기 | 기술 |
|---|---|---|
| 하는 일 | 조건이 맞으면 **행동과 따로** 효과가 붙는다 (자동) | 내 차례에 **기본 공격 대신** 쓰는 행동 |
| 비용 | 없음 | 충전 (차례마다 등급 확률만큼, 2까지 모음) |
| 개수 | 제한 없음 (고유 특기만 인물당 1개) | 제한 없음 —— 카드마다 사다리로 붙는다 |
| 레벨 | 1~9, 수치 배율 | 카드 등급 배율 (원본 SKMUL) |

**기술 여러 개 —— 충전은 하나를 같이 쓴다.** 충전이 1 이상이고 조건이 맞는 기술 가운데 사다리에서 앞선 것 하나를 쓴다.
기술이 많을수록 '더 자주'가 아니라 '더 여러 상황에 맞게' 쓴다 (발동 횟수는 그대로라 등급 격차가 흔들리지 않는다).

**계열(attr)은 없앤다.** 화상 · 수몰 · 와해 · 표식 · 혼란 · 봉인 같은 상태이상은 효과의 한 종류로 남는다. 상태마다 하는 일이 원래 다르다:
화상 = 매 턴 병력 손실 · 수몰 = 느려짐 · 와해 = 쉽게 패주 · 표식 = 아군이 먼저 노림 · 혼란 = 차례를 날림 · 봉인 = 기술 · 고유기 못 씀.
'그 상태인 적을 더 친다' 특기는 상태마다 따로 두지 않고 하나(약점)로 합친다.

## 2. 조건 목록

| 종류 | 조건 |
|---|---|
| 때 | 전투 시작 · 첫 2턴 · 5턴 이후 · 내 차례 시작 |
| 내 상태 | 병력 50% 이하 · 병력 30% 아래로 처음 떨어질 때 · 병력 0이 될 때 · 사기 높음(120 이상) |
| 내 행동 | 공격이 맞을 때 · 책략이 맞을 때 · 치명타 · 기술을 쓸 때 · 적을 무너뜨렸을 때(패주 · 궤멸) |
| 맞을 때 | 공격받을 때 · 큰 피해(최대 병력 10% 이상)를 받을 때 · 상태이상이 걸릴 때 |
| 아군 | 아군이 무너질 때 · 아군이 치료받을 때 · 아군이 고유기를 쓸 때 · 아군이 기술을 쓸 때 |
| 적 | 적이 고유기를 쓸 때 · 적이 무너질 때(누가 했든) |
| 자리 | 선봉 · 전군 · 중군 · 후군에 있을 때 |
| 늘 | 상시 (단체 특기) |

## 3. 효과 목록

피해(물리 · 책략 추가) · 상태이상 걸기 · 강화(공격 · 방어 · 책략 · 책방 · 속도 · 치명) · 약화 · 치료(병력) · 사기 올림 / 꺾음 ·
고유기 게이지 올림 / 깎음 · 기술 충전 올림 / 깎음 · 군령 포인트 · 방진 · 되받아치기 · 버티기(병력 1) · 일으켜 세우기 · 처형 · 추가 행동

## 4. 일반 특기 목록 (안) —— 40종

덱을 짜는 축 8개로 묶었다. 같은 축의 특기를 모으면 덱이 된다. 다른 축과 섞으면 다른 덱이 된다.

### ① 선제 —— 초반에 몰아친다
| 특기 | 조건 | 효과 |
|---|---|---|
| 선봉 | 전투 시작 | 첫 공격 피해 +40% |
| 기습 | 첫 2턴 | 속도 +20% · 치명 +10% |
| 화계 | 전투 시작 | 적 맨 앞 열에 화상 |
| 기선 | 전투 시작 | 적 전원 사기 −10 |
| 철옹성 | 전투 시작 | 아군 맨 앞 열 방진 (2턴) |

### ② 역전 —— 몰릴수록 강해진다
| 특기 | 조건 | 효과 |
|---|---|---|
| 투쟁 | 병력 50% 이하 | 공격 · 책략 +20% |
| 배수 | 병력 30% 아래로 처음 떨어질 때 | 2턴 동안 공격 · 책략 +40% · 받는 피해 −20% |
| 사수 | 병력 0이 될 때 (한 번) | 병력 1을 남기고 버틴다 |
| 불굴 | 병력 50% 이하 | 패주 확률 −50% |

### ③ 복수 —— 아군이 쓰러질수록 강해진다
| 특기 | 조건 | 효과 |
|---|---|---|
| 비분 | 아군이 무너질 때 | 공격 · 책략 +12% (전투 끝까지 쌓임) |
| 결사 | 아군이 무너질 때 | 사기 +20 · 고유기 게이지 +20 |
| 도원결의 | 아군이 처음 무너질 때 (한 번) | 병력 30%로 일으켜 세운다 |

### ④ 연쇄 —— 하나를 무너뜨리면 굴러간다
| 특기 | 조건 | 효과 |
|---|---|---|
| 기세 | 적을 무너뜨렸을 때 | 다음 공격 피해 +50% |
| 승세 | 적을 무너뜨렸을 때 | 기술 충전 +0.5 |
| 추격 | 적을 무너뜨렸을 때 (차례마다 한 번) | 바로 한 번 더 공격 |
| 궤멸 | 적이 무너질 때 | 같은 열 적에게 와해 |

### ⑤ 공격이 맞을 때 —— 상태이상을 건다
| 특기 | 조건 | 효과 |
|---|---|---|
| 점화 | 공격이 맞을 때 | 확률로 화상 (매 턴 병력 손실) |
| 침수 | 공격이 맞을 때 | 확률로 수몰 (느려짐) |
| 충파 | 물리 공격이 맞을 때 | 확률로 와해 (쉽게 패주) |
| 조준 | 원거리 · 책략이 맞을 때 | 확률로 표식 (아군이 먼저 노림) |
| 반목 | 책략이 맞을 때 | 확률로 혼란 (차례를 날림) |
| 봉쇄 | 책략이 맞을 때 | 확률로 봉인 (기술 · 고유기 못 씀) |
| 약점 | 상태이상 걸린 적을 칠 때 | 피해 +25% |
| 교란 | 공격이 맞을 때 | 적 사기 −6 |

### ⑥ 맞을 때 —— 받아치고 버틴다
| 특기 | 조건 | 효과 |
|---|---|---|
| 반격 | 공격받을 때 | 확률로 되받아친다 |
| 방진 | 내 차례 시작 | 확률로 방진 (받는 물리 피해 −30% · 반격 +, 2턴) |
| 역습 | 방진 중 공격받을 때 | 되받아치는 피해 +100% |
| 금강 | 큰 피해를 받을 때 | 그 피해 −30% |
| 축기 | 공격받을 때 | 고유기 게이지가 더 빨리 찬다 (+50%) |

### ⑦ 지원 —— 아군을 살린다
| 특기 | 조건 | 효과 |
|---|---|---|
| 인술 | 내 차례 시작 | 가장 지친 아군 하나 치료 |
| 위무 | 공격이 맞을 때 | 가장 지친 아군을 조금 치료 |
| 분발 | 아군이 치료받을 때 | 그 아군 2턴 공격 · 책략 +50% |
| 호응 | 아군이 기술을 쓸 때 | 내 기술 충전 +0.25 |
| 고무 | 아군이 고유기를 쓸 때 | 아군 전원 사기 +10 |

### ⑧ 견제 —— 상대의 한 방을 막는다
| 특기 | 조건 | 효과 |
|---|---|---|
| 간파 | 적이 고유기를 쓸 때 | 아군 전원 그 턴 받는 피해 −30% |
| 탈기 | 책략이 맞을 때 | 적 고유기 게이지 −10 |
| 명경 | 상태이상이 걸릴 때 | 확률로 막아 낸다 |
| 단량 | 늘 (적 전원) | 적이 받는 치료 절반 |

### 단체 (상시, 아군 전원) —— 그대로 5종
공세(공격 · 책략) · 결속(방어) · 후원(책략 · 책방) · 보급(병력 · 회복) · 군주(사기) —— 군령 연결도 그대로.

## 5. 지금 특기에서 옮기는 법

| 지금 | 새 |
|---|---|
| 화공 · 수계 · 짓밟기 · 명중 · 허실 (상태별 '더 친다') | **약점** 하나 |
| 화염일격 · 수격 · 충돌 · 관통 (같은 추가 피해) | 그 인물 축에 맞는 것으로 (선봉 · 기세 · 교란 …) |
| 천우 · 제방 · 호위 · 은폐 (상태별 저항) | **명경** 하나 |
| 신속 | 선봉 / 기습 |
| 용맹 | 기습 또는 기세 (치명을 쓰는 축) |
| 귀모 | 승세 또는 호응 (기술을 쓰는 축) |
| 위압 · 위풍 | 기선 |
| 반간 | 반목에 합침 |
| 감읍(분발) · 인술 · 위무 · 도원결의 · 단량 · 방진 · 반격 · 역습 · 철옹성 · 사수 · 궤멸 | 그대로 (조건 × 효과로 다시 적음) |

- 인물마다 무엇을 받을지는 고증과 지금 사다리를 바탕으로 다시 배정한다 (장비 = 투쟁 · 기선, 조운 = 기세 · 추격, 화타 = 인술 · 분발 …).
- 고유 특기 43종은 그대로 둔다 (인물 정체성). 안의 장치만 새 조건 × 효과로 다시 적는다.

## 6. 기술 (여러 개)

- 원본 SKILLPOOL 24종을 병종 전용에서 **범용**으로 푼다 (동탁도 화공 기술을 들 수 있다).
- 카드마다 기술 사다리: 희귀 1 → 전설 2 → 초월 이상 2~3 (인물 성격대로, 개수 제한 없음).
- 조건은 지금처럼 기술마다 (`skill_cond`), 충전은 카드 하나에 하나.

## 7. 순서

1. 이 목록 확정 (사용자)
2. 엔진: 조건 이벤트 걸이(무너뜨림 · 아군 무너짐 · 고유기 사용 · 큰 피해 …) 추가, 특기를 조건 × 효과 표로 읽게
3. 특기 40종 데이터 · 인물 배정 · 레벨
4. 기술 여러 개 (공유 충전) · 범용 기술 배정
5. 측정: 축마다 켬/끔 차이 (목표 +10~15%p), 한 등급 위 상대 0%, 15턴 · 결정성
