# 특기 · 기술 개편 —— 조건 × 효과 (설계안 3판, 2026-10-30)

사용자 결정:
- 특기는 '언제(조건) + 무엇을(효과)'로 짠다 (1안). 기술은 카드당 여러 개 (충전 하나를 같이 씀). 인연 시너지는 넣지 않는다.
- **표적 계열(표식) 관련 데이터는 모두 없앤다.**
- 큰 축: **피해 3 (도트 · 물리 · 책략) + 디버프 4 (방깎 · 책방깎 · 속도 하락 · 스턴) + 철벽 · 인덕(지금 그대로).** 단일 · 광역은 나누지 않는다 (3판).
- **파갑 · 현혹은 정해진 % 가 아니라 장수마다 다른 수치를 맞힐 때마다 계속 깎는다** (3판).

---

## 1. 상태이상 정리

| 상태 | 하는 일 | 지금에서 |
|---|---|---|
| **화상** (도트) | 차례마다 최대 병력의 일정 비율을 잃는다 | 화상 그대로. **출혈은 화상으로 합친다** (같은 일을 하던 상태) |
| **파갑** (방깎) | 맞힐 때마다 방어를 **수치로** 깎아 쌓는다 (전투 끝까지, 원래 방어의 절반까지). 깎는 양은 장수마다 다르다 (특기 레벨 · 카드 등급) | 와해(받는 피해 + · 패주 ×2)를 바꾼다 |
| **현혹** (책방깎) | 책략이 맞을 때마다 책략방어를 **수치로** 깎아 쌓는다 (전투 끝까지, 원래 책방의 절반까지). 깎는 양은 장수마다 다르다 | 새로 (기술의 resDown 도 이것으로) |
| **둔화** (속도 하락) | 속도 −30% (2턴) | 수몰(잠김)을 바꾼다 |
| **혼란** (스턴) | 차례를 한 번 날린다 | 혼란 그대로. **봉인은 혼란으로 합친다** |
| ~~표식~~ | —— | **없앤다** |

- 역병(사기가 매 턴 깎임)은 원본 술사 기술 · 장로 고유기에만 있다 —— 그대로 둔다 (특기 축에는 넣지 않음).
- 방진(철벽) · 분발(인덕)은 버프라 그대로.

## 2. 일반 특기 목록 (안) —— 34종

조건은 1안 그대로 섞어 쓴다 (전투 시작 · 첫 2턴 · 병력 50% 이하 · 공격이 맞을 때 · 적을 무너뜨렸을 때 · 아군이 무너질 때 …).

### 피해 ① 도트 (화공)
| 특기 | 조건 | 효과 |
|---|---|---|
| 점화 | 공격이 맞을 때 | 확률로 화상 |
| 화계 | 전투 시작 | 적 맨 앞 열에 화상 |
| 연소 | 늘 | 내가 건 화상이 더 뜨겁다 (+50%) |
| 연환 | 적 화상이 탈 때 | 확률로 같은 열 이웃에게 번진다 |

### 피해 ② 물리
| 특기 | 조건 | 효과 |
|---|---|---|
| 선봉 | 전투 시작 | 첫 공격 피해 +40% |
| 용맹 | 물리 공격이 맞을 때 | 치명타 확률 · 피해 + |
| 투쟁 | 병력 50% 이하 | 물리 피해 +25% |
| 기세 | 적을 무너뜨렸을 때 | 다음 공격 피해 +50% |
| 추격 | 적을 무너뜨렸을 때 (차례마다 한 번) | 바로 한 번 더 공격 |
| 휩쓸기 | 물리 공격이 맞을 때 | 같은 열 이웃에게 피해 30% |

### 피해 ③ 책략
| 특기 | 조건 | 효과 |
|---|---|---|
| 귀모 | 책략이 맞을 때 | 책략 치명타 확률 · 피해 + |
| 기책 | 병력 50% 이하인 적을 칠 때 | 책략 피해 +30% |
| 신산 | 기술을 쓸 때 | 그 기술의 책략 피해 +30% |
| 파상 | 책략이 맞을 때 | 같은 열 이웃에게 피해 25% |
| 연계 | 아군이 기술을 쓸 때 | 내 기술 충전 +0.25 |

### 디버프 ① 방깎 (파갑)
| 특기 | 조건 | 효과 |
|---|---|---|
| 파갑 | 물리 공격이 맞을 때마다 | 적 방어 −n (쌓임) |
| 쇄갑 | 첫 공격 | 적 방어 −3n (한 번에 크게) |

### 디버프 ② 책방깎 (현혹)
| 특기 | 조건 | 효과 |
|---|---|---|
| 현혹 | 책략이 맞을 때마다 | 적 책략방어 −n (쌓임) |
| 요언 | 전투 시작 | 적 전원 책략방어 −2n |

n 은 특기 레벨로 정한다 (예: 레벨 × 2 —— 고급 Lv1 이면 2, 신화 Lv9 면 18). 같은 적을 여러 장수가 치면 그만큼 빨리 깎인다 —— 파갑 · 현혹 장수를 모으면 덱이 된다.

### 디버프 ③ 속도 하락 (둔화)
| 특기 | 조건 | 효과 |
|---|---|---|
| 침수 | 공격이 맞을 때 | 확률로 둔화 |
| 수계 | 전투 시작 | 적 전원 둔화 (1턴) |

### 디버프 ④ 스턴 (혼란)
| 특기 | 조건 | 효과 |
|---|---|---|
| 반목 | 책략이 맞을 때 | 확률로 혼란 |
| 위압 | 사기가 낮은(60 이하) 적을 칠 때 | 확률로 혼란 |
| 반간 | 적 혼란이 풀릴 때 | 같은 열 이웃에게 한 번 옮겨 간다 |

### 디버프 공통
| 특기 | 조건 | 효과 |
|---|---|---|
| 약점 | 디버프 걸린 적을 칠 때 | 피해 +25% |
| 명경 | 디버프가 걸릴 때 | 확률로 막아 낸다 (상태별 저항 천우 · 제방 · 호위 … 는 이것 하나로) |

### 철벽 (그대로) —— 방진 · 반격 · 역습 · 철옹성 · 사수
### 인덕 (그대로) —— 인술 · 위무 · 분발 · 도원결의 · 단량
### 단체 (상시, 아군 전원) —— 공세 · 결속 · 후원 · 보급 · 군주

## 3. 없애는 것

- **표적 계열 전부:** 조준 · 명중 · 관통 · 은폐 · 연노 · 집중사격 · 속사 · 백보천양(연쇄 표식) · 원문사극(표식→와해), 표식 상태, `passives.json aim`, 엔진의 표식 처리, 시험 `attr --attr=표적`.
- **표적을 쓰던 고유 특기는 다시 짠다:** 손권 「벽안」 · 하후연 「질풍」 · 황충 「확삭」 · 태사자 「신의」 · 여포 「비장」.
- 효과가 같던 추가 피해 4종(화염일격 · 수격 · 충돌 · 관통) → 물리 · 책략 축의 특기로.
- 상태별 '더 친다'(화공 · 수계 옛 정의 · 짓밟기 · 명중 · 허실) → 약점.
- 계열(attr) 내부 분류 → 위 축(도트 · 물리 · 책략 · 방깎 …)으로 바꾼다. 특기판 색도 축별로.

## 4. 기술 (여러 개)

- 원본 기술 24종을 병종 전용에서 범용으로 푼다. 기술의 상태 효과는 위 1장대로 바꾼다 (출혈 → 화상, 봉인 → 혼란, resDown → 현혹, 수몰 → 둔화).
- 카드마다 기술 사다리: 희귀 1 → 전설 2 → 초월 이상 2~3. 충전은 카드 하나에 하나, 조건이 맞는 기술 하나를 쓴다.
