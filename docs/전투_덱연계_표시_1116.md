# 전투 덱 연계 표시 1차 (2026-11-16)

전투 판정과 밸런스를 바꾸지 않고 기존 사건을 읽어 표시한다.

- 전장 메달 아래에 화상·둔화·방깎·책방깎·혼란 상태명을 최대 두 개 표시한다. 2D 메달과 3D 초상 머리표 양쪽에 적용한다.
- 출처 `from`이 있는 불길·물길 확산은 출처 부대 위에 이름을 띄우고 대상으로 향하는 선과 이동점을 0.85초 보여준다.
- 실제 피해 사건의 `fire` / `water` 추가 피해 플래그가 있을 때만 공격자에게 화상 활용 / 수몰 활용을 표시하고 대상으로 연결한다. 단순히 대상에게 상태가 있다는 이유로 추가 피해를 추정하지 않는다.
- 같은 대상·효과의 알림은 4초 간격이며 연결선은 최대 세 개다. 전투를 다시 시작하면 기록을 비운다. 컷인은 기존처럼 가장 위에 그린다.

현재 데이터의 `flood` 명칭은 둔화다. 과거 표적·와해 계열 설명과 달리 현재 상태 표에는 mark/break가 없어 해당 상태를 새로 만들지 않았다.

제한: 일반 상태 부여 사건에는 시전자 정보가 없는 경우가 있다. 이 경우 대상에 상태명만 표시하며 출처를 추정하지 않는다. 방깎을 활용해 증가한 피해의 별도 판정·기여 집계와 편성 추천은 이번 범위에 없다. 화면이 복잡한 접전에서 가독성은 추가 플레이 평가가 필요하다.
