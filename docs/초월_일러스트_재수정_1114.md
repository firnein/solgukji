# 초월 일러스트 재수정

사용자 화풍 기준: `prompts/등급별_v2/3_불멸/서황.png`.

- 참고하는 요소: 또렷한 먹선, 그려진 눈매와 이목구비, 면으로 나눈 피부 명암, 의복과 금속에 집중한 붓 질감.
- 얼굴: 모공·사진 같은 피부·젖은 눈·과한 피부 주름 묘사를 피한다. 성인 체형을 유지하되 분명한 2D 일러스트로 그린다.
- 초월 등급: 차분한 푸른 하늘과 흐릿한 군기, 은색·강철 장식, 인물별 복색과 상징물. 불멸 참고 그림의 어두운 역광·불티·과장된 장식은 가져오지 않는다.
- 기인처럼 보이는 청록 원형 효과, 벚꽃 궁궐 배경, 치비 비율을 제거한다.
- 교체 대상: 능통, 원술, 대교, 소교, 장소, 등애, 정보, 종회, 화웅, 우길, 황개.
- 게임 파일은 기존 경로와 파일명을 유지하고 최대 변 600px로 저장한다.

검수 도구: `references/prepare_transcend_art.gd`(크기 정리), `references/review_transcend_art.gd`(실제 CardView와 CardTile 렌더).

원본 비교: `references/transcend_review.png`. 최종 카드 검수: `references/transcend_cards_after.png`.

완료: 교체 대상 11장 적용, 최대 변 600px 정리, Godot 재임포트 성공. 실제 초월 카드 15장과 작은 CardTile을 렌더해 얼굴·이름 칸 겹침 없이 표시되는 것을 확인했다. 기존 관평·문추·방덕·주태는 유지했다.
