# 장수 특기 역할표와 1차 조정안

> 현재 데이터 기준. 이 문서는 실제 특기 교체 전에 의도한 역할을 고정하기 위한 편성표다. 수치 변경은 전투 기여 측정 뒤 반영한다.

## 먼저 고칠 구조 문제

현재 전투는 `int`를 `atk`에 더한다(`Battle.MV_ALIAS`). 따라서 데이터에 `atk`와 `int`가 함께 적힌 특기는 공격과 책략을 따로 올리는 게 아니라 **같은 공격 수치에 둘 다 더했다**. 11/10 정리에서 특기 데이터의 `int` 키를 `atk`로 합치고, 중복 상승이던 세 특기는 공격 한 번만 오르도록 조정했다.

| 특기 | 기존 데이터 | 기존 실제 효과 | 반영한 조정 |
|---|---|---|---|
| 공세 | atk 8% + int 8% | 공격 16% | 공격 8%로 조정. 공세 효과와 군령 연계가 주 역할 |
| 간웅 | atk 6% + int 6% + def 5% | 공격 12% + 방어 5% | 공격 6% + 방어 5%로 조정. 보유자 화공이 고유 역할 |
| 괄목 | atk 6% + int 6% | 공격 12% | 공격 6%로 조정. 후군 수몰이 주 역할 |
| 수경 | int 8% + def 6% | 공격 8% + 방어 6% | `ally_sk` 1%로 교체. 아군 기술 연계 지원 |
| 후원 | int 6% + def 8% + rate 3% | 공격 6% + 방어 8% + 기술 충전 3% | 공격 상승을 제거. 방어·기술 충전과 군령 포인트 시작을 맡김 |
| 왕좌 | int 6% + def 6% + rate 2% | 공격 6% + 방어 6% + 기술 충전 2% | 공격·방어를 시작 사기 6으로 교체. 기술 충전은 유지 |
| 황천 | 병력 회복 3.5% + 사기 회복 4 | 병력·사기 회복 | 병력 회복을 제거. 사기 회복과 보유자 상태이상 강화로 분리 |

공세·간웅·괄목의 공격 하향은 옛 공격/책략 보너스의 중복 합산을 제거한다. 후원·수경·왕좌·황천은 단체 특기끼리 역할이 겹치는 효과를 각기 방어·연계·사기·사기 회복으로 재배치했다.

특기 데이터에서 `int`로 저장되던 공격 보너스는 `atk`로 정규화했다. 특기 이외 데이터에는 기존 별칭 처리를 유지한다.

위세(`lines.json aura`)에도 같은 겹침이 둘 있어 함께 고쳤다(11/11): 초월 원술 중가제위 `atk + int`(각 11.2%, 실제 22.4%) → `atk` 11.2% 하나, 기인 방통 연환 `cleave + icleave`(각 10%) → `cleave` 10% 하나. 화면에는 원래부터 한 번만(큰 값) 보였으므로 표시 수치는 그대로이고 실제 효과가 표시와 같아진다.

## 특기 사다리 채움 정리

`db.gd`는 `lines.json`의 `ladder`를 `passives.json`의 사다리 위에 덮어쓴다. 예전 `lines.py`의 `fill_ladders`는 등급마다 최소 특기 수(TRAIT_MIN 3~8)를 맞추려고 뒤 등급 특기를 앞당기고, 모자라면 같은 병종 인물들이 많이 가진 특기를 억지로 붙였다(11/9 `trim_filler`가 그 일부만 다시 뺐다). 그 결과 인물 성격과 무관한 특기가 붙고, 같은 병종끼리 특기 구성이 비슷해졌다.

- 작성된 사다리(`passives.json ladder`, `LADDER_FROM`으로 빌린 사다리)는 손대지 않고 그대로 쓴다 —— 앞당기기·병종 채움·trim 모두 없앴다.
- 원래 사다리가 없는 저등급 인물 43명은 `tools/scripts/lines.py`의 `PERSONAL_SPECIALTIES`로 인물마다 직접 고른 개인 특기 3개를 준다(단체·고유 특기는 쓰지 않는다 —— 스크립트가 assert 로 확인).
- 세 특기는 그 인물의 가장 낮은 플레이어 카드 등급부터 모두 열린다. 순서는 카드에 보이는 순서다.

그래서 `lines.json`의 `ladder`에는 이 43명만 남는다(11/10 이전 97명 · 443칸 → 43명 · 129칸). 나머지 54명은 작성된 사다리로 돌아가 특기 수가 줄었다 —— 전체 밸런스 측정 때 같이 본다.

## 실제 조정 순서

1. **설명부터 판정과 일치시킨다.** `책략 상승`처럼 별도 능력치로 오해하게 하는 표현을 현재 통합 공격/방어 기준으로 고친다. 범위·조건·중복 규칙을 함께 적는다.
2. **전원 버프를 주 역할 하나씩으로 재배치한다.** 공격, 생존, 회복, 사기, 기술 순환 중 무엇을 제공하는지 고정하고, 같은 능력치 묶음이 반복되는 특기는 일부를 조건부/대상 한정 효과로 바꾼다.
3. **고유 특기의 다중 효과를 검토한다.** 비장처럼 화력·방어 파괴·마무리를 동시에 주는 특기는 정체성은 유지하되 역할 내 총 기여가 튀는지 등급별로 확인한다.
4. **특기별 발동 로그를 보강한 뒤 수치를 조정한다.** 보유자·조건 충족·효과 적용·피해/회복/제어 결과를 분리 집계한다. 단순 키 조회 횟수로 밸런스를 정하지 않는다.
