# 전투 개선 현황

기준: 2026-11-17, `origin/main`의 `b3bfb39`에서 `fix/battle-motion5` 생성.

## motion.5 APK 기준 확인

현재 저장소·원격 브랜치·커밋 메시지·로컬 build 폴더에서 `motion.5`를 식별하지 못했다. 현재 확인 가능한 최신 APK 기록은 **1.0z / code 27**이다. motion.5의 소스 커밋/브랜치 또는 로컬 APK 경로를 사용자에게 요청했다. 아래 1.0z 작업을 motion.5 완료 작업으로 간주하지 않는다.

## 현재 코드에서 확인한 완료 작업

- 삽화 병사와 군기, 병종별 대표 대열, 피격 움찔과 병력 감소 빈자리, 패주 표시.
- 원근을 둔 고정 사선 투영, 세로 뷰포트 프레이밍, 지면 역투영, 화살·연계 입자 투영.
- 기존 군집/전쟁 삽화 전환, 일시정지, 사건 재생 검증. 과거 결정성 30판 통과 기록.

## 우선 결함 및 진행

| 항목 | 확인한 문제 | 상태 |
|---|---|---|
| 원거리 기본 공격 | 궁병·책략계가 `back1` 후열 규칙으로 사거리 밖 적까지 선택 가능. 이동 목표에도 기존 목표 가중치가 있음 | 수정 예정 |
| 원형 고유기 범위 | `_ult_area`가 판정 반지름에 40을 더해 기록, DotView는 다시 0.6배 축소하고 화면 원으로 그림. 사선 원근 투영과 불일치 | 수정 예정 |
| 고유기 예고 | 실제 범위 대신 대상마다 반지름 60의 원을 표시하며, 미리보기에서 과거 사건에 범위를 기록할 수 있음 | 수정 예정 |
| motion.5 대열·타격 복원 | 기준 소스/APK 미확인 | 자료 대기 — 복원 완료로 보고하지 않음 |
| 실기기 프레임 저하 | `adb devices -l` 결과 연결 기기 없음 | 기기 대기 — PC FPS로 대체하지 않음 |

## 검증 원칙

사거리 판정은 기존 대열 발자국 사이의 간격을 유지하고, 그 안에서 중심 거리가 가장 가까운 생존·비은신 적을 고른다. 고유기는 판정 수치를 바꾸지 않고, 그 수치와 동일한 월드 도형을 표시한다. 예고는 준비 시점의 위치 기준이며 실제 발동 시 적이 움직이면 결과가 달라질 수 있다. 범위에 발자국 일부가 닿으면 중심이 원 밖이어도 맞을 수 있다.

motion.5를 확보한 뒤 복원 전후 동일 편성/시드로 비교한다. 실기기는 모델·OS·화면 크기·품질·발열 조건을 기록하고, 평균 FPS뿐 아니라 프레임 시간 p50/p95/p99, 33.3ms 초과 비율, 교전/고유기 구간을 구분한다. 기기 미연결 상태에서 이 측정을 완료했다고 기록하지 않는다.
