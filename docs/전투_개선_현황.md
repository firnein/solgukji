# 솔국지 전투 개선 현황

복원 기준은 Android `1.0z-motion.5` (versionCode `31`)의 `solgukji-motion-preview.apk`와 Git의 `1.0z` 커밋 `b3bfb39`다. APK의 GDScript 55개를 기준 커밋과 대조해 변경된 스크립트 5개를 복원했다. 기존 Git 소스와 일치하는 부분은 가능한 범위에서 원래 서식과 주석을 살렸다. APK에서 추가·변경된 코드의 원래 주석 일부는 확인할 수 없다.

## 복원된 동작

- 삽화 전장의 대열이 적에게 접근하고, 앞줄이 맞붙으면 뒤에서 보충한다. 피격 반동, 돌격과 강타에 따른 낙하를 재생한다.
- 부대의 장수 이름, 메달, 진영 표시로 식별할 수 있도록 했다.
- 전투 재생 이벤트에 돌격, 무쌍, 한실부흥, 불바다 등의 연출에 필요한 데이터를 담고, 삽화 전장이 이를 받아 재생한다.
- 이전 빌드 작업에서 9대9 전투를 최대 252명 표시로 확인했다. 앞줄 보충, 일시정지와 재시작도 점검했다.

## 코드 위치

| 경로 | 역할 |
| --- | --- |
| `solgukji_godot/scripts/battle.gd` | 고유기 상태와 재생 이벤트 |
| `solgukji_godot/scripts/rt_battle.gd` | 실시간 전투 이벤트 |
| `solgukji_godot/scripts/battle_view.gd` | 재생 타이밍, 이벤트 전달, 전장 표시 |
| `solgukji_godot/scripts/field/war_painting.gd` | 병사와 전장 효과 그리기 |
| `solgukji_godot/scripts/field/painted_formation.gd` | 대열 배치, 접촉, 손실과 보충 |

## 검증

- 복원한 5개 스크립트를 Godot 4.6.3으로 다시 내보내 APK의 코드 토큰과 줄 위치가 모두 일치함을 확인했다.
- 복원 스크립트와 기존 APK 리소스로 Godot 헤드리스 기동을 확인했다. Android 프로젝트의 배포 기준 엔진은 Godot 4.4.1이다.
- 기존 `tests/determinism.tscn`을 실행해 30판 모두 통과했다.
- Android 실기기에서 고유기 표시, 범위, 프레임 시간은 추가 확인이 필요하다.

## 다음 작업

1. 고유기 이벤트 발생부터 화면까지 추적한다. 연출과 실제 피격 대상이 같은 중심·범위·보정값을 쓰는지 불바다 등의 재현 전투에서 확인한다.
2. 같은 9대9 덱과 시드로 기기에서 프레임 시간을 비교한다. 대열 갱신, 병사 그리기, 효과를 각각 측정해 화면 요소가 줄었는데도 느려진 원인을 찾는다.
3. 원거리 부대의 일반 공격은 사거리 안의 가까운 적을 우선하도록 조정한다. 기병 돌격과 고유기의 별도 타겟 규칙을 함께 확인한다.
4. 원거리 부대와 기병의 일반 전투 기여도를 비교한다. 고유기가 없는 전설 주유가 일반 공격과 전투 역할로 기여하는지 별도로 확인한다.
5. 화살 비행을 여러 발이 퍼졌다가 시간차로 떨어지는 형태로 다듬는다. 8명 부대에서도 병사별 보폭, 접촉, 뒷줄 보충이 자연스럽게 이어지는지 확인한다.
