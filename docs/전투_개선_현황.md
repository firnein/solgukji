# 전투 개선 현황

기준: 2026-11-17. `origin/main`의 `b3bfb39`에서 만든 `fix/battle-motion5` 작업 브랜치.

사용자 요청으로 구현을 중단하고 현재 코드를 스냅샷으로 저장했다. **현재 상태와 다음 작업의 기준은 [클로드 인수인계](클로드_인수인계_motion5.md)**다. 최종 화면·성능 재확인과 APK는 미완료다.

## motion.5 APK에서 복원한 작업

사용자가 올린 `origin/motion-5`의 `d6b983d`를 병합했다. 복원 기준은 Android **1.0z-motion.5 / versionCode 31**의 `solgukji-motion-preview.apk`다. 원 브랜치는 APK의 GDScript 55개를 대조해 변경된 5개 스크립트를 복원했다. `97b7964`는 대열, `0987270`은 판정·재생 이벤트, `d6b983d`는 복원 기록이다. APK 토큰을 Godot 4.6.3으로 대조한 기록은 원 브랜치의 검증이다. 이번 통합·수정은 배포 기준 **Godot 4.4.1**로 검사했다.

- 삽화 병사·군기·병종별 대열, 고정 사선 원근 투영, 세로 뷰포트 프레이밍과 지면 역투영.
- 병사별 보폭, 앞줄 접촉과 타격 반동, 병력 손실에 따른 빈자리와 후열 보충, 회복 시 복귀.
- 제한된 낙하, 화살, 돌격·창벽, 무쌍, 한실부흥, 불바다의 사건 데이터와 화면 재생.
- 작은 장수 메달·이름·진영 표시, 기존 군집/삽화 전환과 일시정지.

초기 최근접·범위 수정은 `2068be4`, 복원 통합과 첫 PC 진단은 `c8e1ca2`다. 이번 후속 작업은 아래 결함을 실제로 수정하고 재검증했다.

사거리의 기존 **대열 발자국 간격** 판정은 유지하고, 그 안에서 중심 거리로 최근접을 정한다. 범위도 판정 수치를 바꾸지 않고 표시를 맞춘다. 발자국이 원에 걸치면 부대 중심이 원 밖이어도 맞을 수 있다. 발자국 표시는 밀집/상한 기술의 **선택 대상 안내**이며 단일 원형 영역을 뜻하지 않는다. 예고는 준비 시점, 발동 표시는 발동 시점 기준이라 그 사이 적이 움직이면 대상이 바뀔 수 있다.

그림자는 지면의 한 레이어로 모으고, 병사는 기존 깊이 순서를 유지한다. 바닥/시체 → 병사 → 타격/공중 낙하/상태/화살 순서를 유지하도록 효과 레이어를 분리했다. 표시 인원이나 타격·고유기 개수를 성능 측정을 위해 줄이지 않았다.

## 후속 수정의 재생·성능 확인

기여 문구·상태명·접촉선을 포함한 후속 PC 측정은 평균 **8.33ms**, p95 **11.56ms**, 최대 **18.23ms**, 33.3ms 초과 **0%**, 평균 그리기 **576회**였다. 이는 **마지막 확산 제공자/경로 분리 전 측정**이며 해당 수정 이후 최종 재계측은 사용자 중단 요청으로 남겼다. 위 7.31ms 표는 앞선 최적화 커밋의 결과다. 실행 간 편차가 있으므로 1.02ms 차이 전체를 새 기능의 비용으로 단정하지 않는다. 앞선 후속 탐색은 평균 8.57ms였다. 원본: [후속 측정](benchmarks/motion5_pc_remaining_final.json).

겹침 표본은 시드 5100 동일 편성의 8초 부근에서 수정 전 6쌍, 수정 후 0쌍, 20초 부근에서도 0쌍이었다. 기준은 **서로 다른 진영 병사의 발 위치 거리 < 작은 쪽 표시 병사 높이의 20%**다. 모든 실루엣이 겹치지 않는다는 의미는 아니다. 사선 전장의 자연스러운 가림은 유지한다. 실제 캡처 시간과 쌍은 [표본 원본](benchmarks/motion5_contact_samples.json)에 있다.

## 남은 확인·제작

- **Android 실측:** 기기 연결 불가로 미완료. 연결 가능 시 모델·OS·발열 조건, 프레임 시간 p50/p95/p99, 33.3ms 초과 비율, 교전/고유기 구간을 확인해야 한다.

- **원화 자산:** `전쟁삽화_구현_1116.md`에 남겨 둔 방향별 병사 그림·팔다리/공격 동작 원화 프레임, 나무·강가의 추가 삽화는 이번 코드 수정으로 제작된 것이 아니다. 현재 아틀라스와 연속 메시 변형을 사용한다. 근접 발 위치 겹침 개선과 새 원화 제작을 같은 완료 항목으로 취급하지 않는다.
