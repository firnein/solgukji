## 2. 단계별 작업

### 1단계 — 스케일 (토탈워)

목표: 화면에 "군대"가 보인다. 부대가 점이 아니라 **대열 덩어리**로 보이고, 전장 전체가 한눈에 들어오되 줌하면 병사 하나하나가 보인다.

1. **인형 복제 → 실제 자리 복제** (`type2_view.gd` `_draw_dots`, `CLONE_OFF`): 복제 인형을 랜덤 오프셋이 아니라 **대열 격자의 빈 칸**(병사 사이 중간점)에 두어 대열이 촘촘한 직사각형으로 보이게. 복제는 원본 병사의 `look`·`walk` 위상을 따르되 위상을 0.15~0.35 어긋나게.
2. **깊이감**: 화면 아래(가까운) 부대 인형을 1.0, 위(먼) 부대를 0.82 배로 — `map()` 의 y 로 선형. 위 부대부터 그리는 정렬은 그대로.
3. **대열 종류별 모양**: 창병은 촘촘한 밀집(간격 ×0.9), 기병은 쐐기(앞줄 좁게·뒤 넓게, 말 인형), 궁병은 2열 산개(간격 ×1.25), 책략계는 둘러싼 호위 한 줄 + 가운데 장수. `squad.gd` `_desired()` 의 격자 계산에 병종별 배율표 `FORM_SHAPE` 를 더한다. 병사 수·판정은 그대로.
4. **깃발·군기**: 부대마다 장수 메달 뒤에 세력색 깃발 1개(인형과 같은 MultiMesh, 바람에 흔들리는 사인 파형). 전설 이상은 깃발 2개. 11/6에 뺀 깃발을 "성씨 글자 없이, 작게" 되살린다.
5. **전장 전체 보기**: 전투 시작 0~2초는 전체가 들어오게(`_fit`), 첫 격돌 뒤 `cam_fx` 에 따라. 일시정지하면 전체 보기 + 모든 부대 이름.

검증: `--gtype2=1 --gnew=70 --gplay=8 --gpage=war --gbattle=quest --gshot=... --after=3` 과 `--after=12` 두 장. 후반 대전(`--gnew=6 --gplay=17 --gbattle=pvp`)에서 `--gfps=20` 평균 fps ≥ 60(PC).

### 2단계 — 군집의 자연스러움

목표: 부대가 미끄러지지 않고 **걷고, 부딪치고, 밀리고, 흩어지고, 다시 모인다**.

1. **가속·감속**: `squad.gd` `update()` 의 `pos += dir * speed * dt` 를 속도 벡터 `vel` 로 바꿔 가속 0.6초·감속 0.4초. 방향 전환은 `TURN` 그대로. 판정 좌표(rt_battle)는 그대로이고 보이는 자리만 부드럽게 — 보이는 자리와 판정 자리의 차가 30px 를 넘으면 따라붙는다.
2. **충돌 밀림**: 맞붙은 두 부대의 앞줄이 서로 `CONTACT_GAP` 안으로 파고들면 양쪽 병사가 뒤로 밀리는 파동(앞줄부터 0.1초씩 늦게). 이미 있는 `stagger()` 를 "줄 단위 지연" 으로 확장.
3. **대열 이탈과 복귀**: `loose` 가 오를 때 병사마다 `free` 방향으로 흩어지는 양을 병사 위치에 따라(앞줄 많이·뒷줄 적게) 다르게. 떨어진 뒤 `LOOSE_OUT` 복귀 때 뒷줄부터 제자리로.
4. **추격·패주**: 패주(`flee`) 부대는 직선이 아니라 S 자로 흩어지며 뒤처지는 병사가 생기고, 추격하는 부대의 앞줄 몇 명이 조금 더 앞으로 나간다(판정 무관, 보이는 자리만). 쓰러진 병사는 1.5초 누워 있다가 바랜다.
5. **군마**: 기병 인형은 말+기수 한 덩어리. 달릴 때 상하 흔들림(사인), 멈추면 제자리 발구름.
6. **장수**: 장수 인형은 부대 앞 가운데, 맞붙으면 앞줄과 나란히(이미 있음). 고유기 직전 한 발 앞으로 나가고 부대가 멈춘다(1단계 연출 선행).

검증: 1배속 20초 녹화(스크린샷 8장, `--frames=8 --every=1.5`)에서 미끄러짐·순간이동 없음. 결정성 30판 실패 0.

### 3단계 — 호쾌한 기술·고유기 연출 (진삼국무쌍)

목표: 고유기 한 방이 **화면을 장악**한다. 기술은 짧고 굵게, 고유기는 "예고 → 폭발 → 여운" 3박자.

1. **고유기 3박자** (`type2_view.gd` `fx_ult_charge`/`fx_ult`, `battle_view.gd` `_start_ult`):
   - 예고(기 모으기 2.5초): 화면 가장자리 비네트 + 시전 장수 확대(현재 `focus` 1.9배) + 시전자 둘레 빛 고리가 조여듦 + 대상 부대 발밑 붉은 예고 원(이미 `warn`에 있음). 배속과 무관하게 실제 0.6초는 느리게(슬로모션 0.4배).
   - 폭발(0.3초): 한 프레임 흰 섬광(지금 22% → 고유기만 45%), 흔들림, **검기/불기둥/번개/돌풍을 화면 크기의 1/3 이상**으로(현재 fx 반지름 26~48px 를 100~160px 로), 맞는 부대 병사 전체가 `stagger` + 뒤로 밀림 + 일부 공중으로(`air`).
   - 여운(1.2초): 피해 숫자를 한 덩어리로 크게(합산), 쓰러지는 병사 연쇄(0.05초 간격), 땅에 흔적(검흔·불탄 자국·얼음) 5초.
   - vfx 종류별 모양(`fx_ult` 의 `match vfx` 가지): slash=부채꼴 검기 3연속, charge=돌격 궤적 흙먼지+맞는 줄부터 쓰러짐, firestorm=불기둥 3개+잔불, thunder=번개 8줄기+섬광, whirlwind=소용돌이+병사 날림, roar=충격파 원 2겹+전원 stagger, poison=안개 지속, illusion=분신 잔상, shadow=암전 뒤 일격.
2. **일반 기술**: 0.5초 안에 끝난다. 시전자 메달 위 기술 이름 띠(이미 `skill_banner`) + 대상에 종류별 짧은 연출(기존 `fx_minor` 재사용) + 흔들림 작게. 범위 기술은 맞는 부대 전부에 동시에.
3. **잔기술**: 지금처럼 부대 위 이름표만. 연출은 작게.
4. **타격감**: 치명타는 숫자 1.4배 + 흰 테두리 + 맞는 부대 0.2초 흰빛. 격파는 메달 깨짐(이미 있음) + 부대 전체 쓰러짐 연쇄 + 흙먼지 큰 원.
5. **소리**: 고유기 폭발에 `horn` + `crit` 겹치기(이미 있음), 슬로모션 동안 효과음 피치 0.8.

검증: 전투 실험실에서 불멸 9장 vs 불멸 9장 관전, 고유기 터지는 순간 스크린샷 2장(예고·폭발). `cam_fx=1` 에서도 아군 고유기는 연출이 다 보여야 한다.

### 4단계 — 정보 계층 (무엇이 일어나는지 보이게)

`docs/개선_계획_1106.html` #16 의 S/A/B/C 표를 따른다. S(고유기·격파·총붕괴·위세) = 화면 중앙 띠 + 메달 강조, A(연쇄·위험) = 가장자리 고정 칸, B(기술·치명타·상태) = 부대 위 이름표 1개, C(평타 숫자) = 설정으로 합산/숨김. 전투 시작 3초에 내 덱의 핵심(위세·연쇄 축·신화) 소개 띠, 결과표 맨 위에 덱 설계 요약 1줄.
