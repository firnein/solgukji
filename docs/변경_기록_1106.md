## 3차 (2) — #15 마법 개념 삭제 (커밋 6712894)
- **정의:** 계산 통합(B). 공격 = 공 · 책 중 높은 쪽, 방어 = 방 · 책방 중 높은 쪽 (`DB.merge_stats`, 원본 json 은 그대로). 피해 경로는 `phys_hit` 하나 —— `int_hit` 은 범위(aoe) · 반격 없음 · 반목만 남긴 얇은 껍데기.
- **별칭:** 옛 데이터의 int · res, icrit · idr · icleave · cut_int · cut_res, 위세 · 아이템 · 진형 우대 · 기술 버프의 int/res 는 `Battle.S()` · `MV_ALIAS` 로 공격 · 방어에 합산. `rpierce` · `int_low` · `sk_amp` 는 통합 경로에 흡수.
- **뺀 것:** 책략 전용 배율 `int_mul` · `int_tier` · `int_troop` · `INT_LOW` · `strat_int` 등 4개 역할 배율. 책략계 줄 배율은 예전 `LINE.int`(뒤에서 세다)을 공격에 씀.
- **판단:** 평타 종류 · 잔기술 무력판 · 덱 성향 · 사거리는 능력치 대신 병종(`INT_TAG`)으로.
- **화면:** 능력치 3칸(공격 · 방어 · 속도, 책략계 공격은 푸른색). 용어 공격 · 방어 (`STATNM` · `MOD_LABEL` · `AURA_M` · 특기 설명문 치환 `TXT_ALIAS`).
- **검증:** 결정성 30판 실패 0 · 자동 진행 정상 · 불멸 20판 역할: 책사 피해 몫 0.66(통합 전 0.87~0.92), 책략계 3장 덱 승률 60~75%(방어가 책방까지 흡수) —— **후속 밸런스**.
