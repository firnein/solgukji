# 전투 중 개입 기획 (고유기 직접 발동 · 군령)

2026-10-22 사용자와 정한 방향과, 그날 구현·측정한 결과.

## 왜
- 최종 목표는 모바일: 카드 뽑기 → 조합 → 유저/봇과 전투 → 더 좋은 카드 조합.
- 모바일에서 1분 넘는 자동 전투를 보기만 하는 건 의미가 적다 → **전투는 20~40초, 그 안에 판단할 순간 2~3번**.
- 자동으로 방치한 유저와, 직접 조작한 유저 사이에 차이를 둔다. 다만 **비슷한 덱끼리 붙을 때 승부를 가르는 정도**(목표 +5~10%p).
  등급 격차를 뒤집을 만큼 크면 안 된다 (덱빌딩 원칙과 같은 선).
- 사용자가 고른 개입 방식: **① 고유기 직접 발동 ② 군령**. (③ 집중 공격 지정 ④ 예비대 투입은 보류)
- 대전 방식: **상대가 접속해 있으면 실시간, 아니면 비동기**(상대 덱을 AI 가 운영).

## 규칙 (구현됨 · `scripts/battle.gd` 상단 상수)
### ① 고유기
- 불멸·신화 장수만. **전투당 1번**.
- 게이지: 제 차례마다 +30 (신화 ×1.2), 잃은 병력 비율 × 80, 때릴 때마다 +6. 100 이면 준비.
- 준비되면 화면 아래 장수 카드가 금빛 → **탭하면 다음 행동 자리에 끼어들어 발동**(컷인·슬로모션은 그대로).
- 같은 진영 고유기 사이에는 최소 행동 4번 간격. 봉인 중엔 못 쓴다.
- 부대 머리표 아래 금빛 막대 = 고유기 게이지. **적 게이지도 보인다** → 터지기 직전에 방진으로 받는 읽기 싸움.

### ② 군령
- 진영 공용 포인트: 행동 6번마다 +1, 최대 3. 명령 하나 2 소모, 효과 2턴.

| 군령 | 효과 | 쓰임 |
|---|---|---|
| 돌격 | 공격 +20% · 방어 -25% | 기본 공세. 방어가 꺾여 역습에 약하다 |
| 방진 | 받는 피해 -30% · 속도 -10% · 받는 고유기 피해 추가 -35% | 적 돌격·적 광역 고유기를 받는다 |
| 재정비 | 사기 +25 · 패주 확률 -60% | 사기를 깎는 상대 |

설계 중 확인한 것: 피해 공식이 대략 공격²/(공격+방어)라서 **공격 +20% ≈ 피해 +35%, 방어 +35% ≈ 받는 피해 -15%** 밖에 안 된다.
그래서 방진은 방어 수치가 아니라 **받는 피해를 직접 줄이게** 했다 (그 전에는 방진이 돌격을 못 이겨 "늘 돌격"이 정답이었다).

### 정책 (AI)
- `auto` 자동: 게이지 차면 바로, 포인트 차면 늘 돌격. —— 방치한 유저·자동 전투 켠 유저
- `smart` 영리: 자동과 같되 ① 적이 돌격 중이거나 적 광역 고유기가 차오르면(게이지 75↑) 방진 ② 적 고유기가 차오르는 중엔 포인트를 아낀다 ③ 회복·격려형 고유기는 아군이 꺾일 때까지 아낀다. —— "잘하는 사람"의 대역, 비동기 대전의 상대 AI
- `manual` 수동: 입력만. —— 직접 조작하는 플레이어

## 구조 (구현됨)
- 입력 = `[행동 번호, 진영, 종류, 값]`. **같은 시드 + 같은 입력 → 언제나 같은 결과**.
- 화면은 탭할 때마다 (시드 + 지금까지 입력 전부)로 전투를 처음부터 다시 계산한다 (한 판 수 ms).
  입력 앞부분은 그대로 나오므로 이미 본 장면은 바뀌지 않고, 뒤 시간표만 갈아 끼운다.
- 결과에 `applied`(적용된 입력)가 남는다 → **리플레이, 서버 검증, 실시간 대전의 입력 교환**에 그대로 쓴다.
- 사건마다 `bd`(그 행동 번호의 입력 판정을 마친 뒤 나온 사건인가)를 적어, 화면이 입력 걸 번호를 정확히 고른다.

## 비동기 상대 AI 전술 (구현됨 · 2026-10-24)
정책 `tac:<고유기>:<군령>` —— 덱 주인이 고른다. `smart` = `tac:영리:영리`.
- 고유기: 즉시(차면 바로) · 영리(값어치 볼 때, 기존 smart) · 위기(아군 평균 손실 35% 넘거나 5부대 이하일 때만)
- 군령: 공세(늘 돌격) · 영리(기존 smart) · 수비(돌격 안 함 · 사기 60 아래면 재정비 · 포인트가 가득 차면 방진)

|---|---|---|

| 즉시:영리 | -0.3 | +10.0 |
| 즉시:수비 | +2.2 | +12.5 |
| 영리:공세 | -9.8 | -1.5 |

⚠ **가위바위보가 안 된다.** "공세"는 누구에게도 이기지 못한다(방진이 돌격을 받아치기 때문). "위기"는 늘 손해. 고유기 즉시/영리 차이는 오차 안.
→ 전술 고르기가 의미 있으려면 공세가 수비를 이겨야 한다. 후보: 돌격 중 방진 상대 피해 감소 일부 무시 · 수비형이 포인트를 쌓아 두는 동안 공세 쪽 포인트 충전 가산 · 위기형 고유기 위력 가산. (사용자 확인 필요)

## 공세·위기 살리기 시도 (2026-10-24 · 사용자 승인 (가)+(다))
**(가) 돌격이 적 방진의 피해 감소를 일부 무시 → 되돌림 (`Battle.breach` = 0, 손잡이만 남김)**
PV 1000 영리 vs 자동: 무시 0 → +4.7 · 0.15 → +2.2 · 0.25 → +1.7 · 0.35 → -0.2 · 0.5 → -4~+2 (섞인 덱 전 구간).
영리 AI 의 우위는 대부분 "적 돌격을 방진으로 받는 읽기"에서 나와서, 방진을 뚫으면 조작 효과가 통째로 사라진다.
그런데도 공세 vs 수비는 -10 → -6 밖에 안 좋아졌다. → 이 방법으로는 공세를 못 살린다.

**(다) 배수진 → 채택**
- 아군 평균 손실 35% 넘거나 5부대 이하일 때 쓴 고유기는 위력 ×1.3 (`Battle.crisis_amp`). 컷인에 「배수진」 표시, 사건에 `crisis: true`.
- 위기 전술은 고유기 장수 **자신이 병력 40% 아래**여도 쓴다 —— 아끼다 못 쓰고 쓰러지는 게 손해의 진짜 원인이었다
  (배율만 1.5·1.8 로 올렸을 땐 -6%p 그대로, 이 조건을 넣자 -6.5 → -2.2).

**특기–군령 연결의 부작용**: 영리 vs 자동 +7.2 → +4.7 (PV 1000). 자동은 늘 돌격이라 맹진·통솔 덕을 더 본다. 섞인 덱 전 구간은 아래처럼 여전히 목표 안.

## 특기–군령 연결 (구현됨 · 2026-10-24)
단체 특기 5종에 `cmd` 를 붙였다 (`tools/scripts/gen_passives.py` CATALOG → `data/passives.json`). 진영 단위, 같은 이름은 가장 센 주인 하나만, 등급 배율(tier_scale) 적용.

| 특기 | 군령 효과 (배율 1.0 기준) |
|---|---|
| 통솔 | 포인트 충전 +0.35 (행동 6번마다 1 → 1.35) |
| 군략 | 포인트 1 을 들고 시작 |
| 맹진 | 돌격의 공격 상승 ×1.5 (+20% → +30%) |
| 창진 | 방진의 받는 피해 감소 ×1.33 (-30% → -40%) |
| 군주 | 재정비 사기·패주 억제 ×1.6 (패주 억제는 최대 90%) |

덱빌딩 재측정 (`tests/deck.tscn --games=150`): 시너지 덱 vs 무작위 전설 75 · 초월 82 · 불멸 76 · 신화 73% / 한 등급 위 0.7~1.3% → 원칙 유지. 결정성 30판 실패 0.
