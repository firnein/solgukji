# 일러스트 규격 (11/14)

새로 그리는 장수 그림은 아래 크기로 맞춘다. 지금 들어 있는 그림은 크기가 제각각이다(기본 143장 정사각 576~713 · 기인은 가로로 넓은 것과 세로로 긴 것이 섞임 · 초월/불멸 높이 600에 폭 336~484 · 신화 768×1152/1024×1536). 게임은 어떤 비율이든 칸을 꽉 채워 그리지만(`Art._draw_anchor`), 같은 규격으로 맞추면 칸마다 잘리는 정도가 같아진다.

## 1. 크기 세 가지

| 종류 | 크기 (px) | 비율 | 쓰는 곳 | 폴더 · 이름 |
|---|---|---|---|---|
| 카드 초상 | **400×520** | 10:13 (0.77) | 조합 · 징집 · 편성 칸 · 카드 상세(132×188) · 결과 타일 | `solgukji_godot/assets/portraits/<인물>[_등급].png` |
| 컷인 · 장면 | **512×768** | 2:3 | 신화 고유기 컷인 · 조합 시트 배경 · 카드 상세 배경 | `assets/portraits/<인물>_신화.png` · `<인물>_장면.png` |
| 얼굴 메달 | **256×256** | 1:1 | 전투 얼굴 · 결과표 원 · 아래 장수 칸 | `assets/faces/<인물>.png` |

카드 칸 크기는 모두 이 비율 근처다: `UI.TILE_L` 86×112 (0.77) · `TILE_M` 68×96 (0.71) · `TILE_S` 46×72 · 편성 칸 60×84 · `CardView` 132×188 (0.70). 400×520 은 가장 큰 칸(132×188)의 2배 이상이라 휴대폰 고해상도에서도 흐리지 않다.

## 2. 그리는 법

- **배경**: 카드 초상 · 얼굴은 **투명 배경(PNG 알파)** 을 권한다. 네 귀퉁이가 투명하면 게임이 그려진 영역(bbox)만 보고 세력색 바탕 위에 얹는다. 불투명 그림(패널째 · 배경 있는 그림)도 되지만 칸 비율과 다르면 가장자리가 잘린다.
- **머리 자리**: 카드 초상은 **머리가 위쪽 40% 안**(얼굴 가운데가 높이의 약 25~32%), 가로 가운데. 머리 위 여백은 높이의 5% 안쪽. 게임은 얼굴을 기준으로 위에 붙여 자르므로(아래 · 발이 먼저 잘린다) 무기 끝 · 깃털이 머리보다 많이 위로 솟으면 그만큼 머리가 아래로 밀린다.
- **얼굴 메달**: 얼굴이 정사각 한가운데, 얼굴 폭이 그림 폭의 약 60%. 둥글게 잘려 쓰이니 네 귀퉁이에는 중요한 것을 두지 않는다.
- **컷인(2:3)**: 그림 전체가 쓰이고, 카드 초상(10:13)으로도 위에서부터 잘려 쓰일 수 있다 —— 머리와 무기 끝은 위아래 10% 안쪽에.
- **글자 금지**: 이름 · 번호 · 서명 · 워터마크 없음.

## 3. 이름

| 등급 | 파일 이름 | 예 |
|---|---|---|
| 기본 (고급 ~ 전설) | `<인물>.png` | `관우.png` |
| 기인 | `<인물>_기인.png` | `가후_기인.png` |
| 초월 | `<인물>_초월.png` | `조운_초월.png` |
| 불멸 | `<인물>_불멸.png` | `관우_불멸.png` |
| 신화 (카드) · 컷인 | `<인물>_신화.png` | `관우_신화.png` |
| 신화 아래 등급의 장면 | `<인물>_장면.png` | `유비_장면.png` |
| 얼굴 메달 | `assets/faces/<인물>.png` | `faces/관우.png` |

`<인물>` 은 칭호 없는 이름 (`DB.person` —— 「난세간웅 조조」 → 조조). 게임은 등급이 높은 그림부터 찾고(기인 → 신화 → 불멸 → 초월 → 기본, `DB._portrait_cands`) 없으면 아래 등급 그림을 쓴다.

## 4. 맞추는 도구

```
python -I tools/scripts/normalize_portraits.py <새그림 폴더 또는 파일> --out <결과 폴더> [--kind card,cut,face] [--face-x 0.5]
```

- 투명 배경이면 그려진 영역만 남기고(bbox trim) → 목표 비율로 덮어 자르고(가로 가운데 · 세로 위에 붙임, 얼굴은 위쪽 띠의 정사각) → Lanczos 로 줄여 `<결과>/card/` · `cut/` · `face/` 에 같은 이름으로 쓴다. 빈 띠(레터박스)는 만들지 않는다.
- 기본 `--kind card,face`. 신화는 `card,cut,face`.
- 원본이 목표보다 작으면 경고를 찍고 늘린다 —— 다시 그리는 편이 낫다.
- 결과 폴더가 `solgukji_godot/assets` 안이면 `--force` 없이는 멈춘다 (기존 그림 보호). 결과를 눈으로 보고 옮긴다.

## 5. 프롬프트

- `tools/scripts/make_tier_prompts_v2.py` 의 시트(여러 명) 프롬프트는 패널 비율을 10:13 으로 적는다 (시트는 1024×1536 · 1536×1024 로 받아 `slice_tier_v2.py` 로 자른 뒤 위 도구로 맞춘다).
- 한 장짜리(신화) 프롬프트는 1024×1536(2:3)으로 받고, 컷인 512×768 · 카드 400×520 으로 맞춘다.
- `make_face_prompts.py` 메달 시트는 메달 약 400px 로 받아 256×256 으로 줄인다.
