# 전쟁 삽화 — 첫 구현

원화 `concepts/battle_painting_01.png`의 방향을 실제 Type2 전투 재생에 적용했다. 엔진·데이터·승패·전투 위치는 그대로다.

## 실행

- 평소처럼 `solgukji_godot/run.bat`으로 게임을 실행한다. 새 기본값은 전쟁 삽화.
- 설정 → 전투 화풍 → 전쟁 삽화 / 기존 군집. 같은 BattleView를 재사용해도 다음 전투에서 전환된다.
- `solgukji_godot/painting_preview.bat`은 화공·궁병·기병·지원 병종이 섞인 실제 엔진 전투를 한 판 재생한다.
- 테스트 장면: `res://tests/formation_preview.tscn -- --painting --mixed --full`. `--baseline`은 기존 군집, 아무 인자 없으면 이전 대표 병사 시안.

## 표현

- 새 4×4 투명 아틀라스: 8병종 × 청/적 2진영. Godot AtlasTexture로 등분하며 원본 이미지를 변형하지 않는다. 축소 시 거칠어지지 않도록 mipmap 사용.
- 보병·궁병은 두 줄, 기병은 쐐기, 지략계는 작은 지휘 집단. 적은 대표 인형으로 각 부대를 표현한다. 병력의 실제 수는 아래 카드와 상단 합계로 유지한다.
- 재생에 기록된 부대 중심·방향을 따른다. 병력 감소는 앞줄의 빈자리와 바닥에 남는 옅은 실루엣으로, 피격은 전열의 짧은 후퇴로, 낮은 사기는 벌어진 간격으로 표현한다. 패주 군기는 기울어진다.
- 얼굴 메달·병력판을 군기와 짧은 장수 이름으로 대체했다. 상세 초상과 병력은 기존 아래 카드에 유지한다.
- 평타·기술의 공중 날리기를 이 화풍에서 생략한다. 기존 광역 입자 대신 작은 먼지·화살 궤적·부대 단위 화염·깨진 방패·둔화 물결·혼란 고리를 그린다.
- 기록에 실제 출처가 있는 확산·화상/수몰 활용은 작은 이동 입자로 연결한다. 출처를 추정하거나 추가 피해를 새로 계산하지 않는다.
- 반복 잔기술 글씨는 숨기고, 큰 타격 숫자는 부대 최대 병력 12% 이상만 1.5초 간격으로 보여준다. 설정의 피해 숫자 '모두'는 원래 숫자 표시를 유지한다. 적 고유기 준비 경고는 한 줄. 인연·고유기 컷인과 군략 공개는 유지한다.
- 전장 바닥에 새 삽화풍 풀·흙 텍스처와 따뜻한 색을 적용하고, 진영 시작선·중앙 경계선은 이 화풍에서 숨긴다. 지형 배치는 기존 화면 규칙을 유지한다.

## 확인과 한계

### 2차 — 고정 사선 시점과 세로 프레이밍

- 기존 탑뷰의 지면 세로 배율 대신 사선 투영과 약한 원근을 적용했다. 가까운 병사·군기는 크고, 먼 부대는 작다. 그림 자체를 세로로 늘리지 않는다.
- 전장 지면의 역투영도 동일한 원근식으로 바꿔 바닥과 병사가 같은 좌표를 따르게 했다. 화살과 연계 입자는 월드 좌표에서 보간한 뒤 투영한다.
- 사용자 추가 피드백에 따라 가로 맞춤에 남던 세로 여백을 별도로 배분한다. 실제 초기 부대의 발자국 모서리를 투영해, 상단 90px와 하단 30px 여백 사이를 사용한다. 병사 확대와 세로 배치는 분리했다. 물리적으로 등방인 카메라가 아닌 모바일 세로 화면을 위한 표현 조정이다.
- 화면 맞춤은 개전 당시 범위를 유지한다. 적이 줄거나 패주해도 생존 부대 중심으로 확대하지 않아 전선의 빈자리가 보인다. 화면 크기가 달라지면 초기 범위를 새 뷰포트에 맞춘다.
- 병사와 군기를 발 위치 기준으로 함께 정렬해, 먼 군기가 가까운 병사 위로 무조건 덮이지 않게 했다. 글자로 된 이름은 읽기 위한 최소 크기를 유지한다.
- 먼 지면의 작은 나무 점무늬는 큰 수목 색 덩어리와 옅은 능선으로 바꿨다.
- 검사 추가: 투영→역투영 왕복 오차 <0.01, 가까운 병사의 원근 배율 >먼 병사, 초기 부대의 좌우·상하 화면 범위, 사용 가능한 세로 영역 활용, 생존 부대가 줄어도 카메라 배율·중심 유지.
- 캡처 파일: `build/painting_oblique_mixed_0.png`, `_8.png`, `_25.png`. 기존 `painting_mixed_*.png`와 비교 가능하다.

- Vulkan 실제 화면으로 540×960 전투를 끝까지 재생했다.
- 같은 편성·시드에서 화풍 켬/끔의 사건 JSON과 양쪽 잔존 병력이 동일함을 검사한다.
- 일시정지 중 대표 대열의 병력 비율이 변하지 않는지, 같은 BattleView에서 기존→삽화 전환 시 중복으로 그리지 않는지 검사한다.
- 결정성 검사 30판 실패 0.
- 400×800 혼합 병종(화공·궁병·기병·지략계) 재생, 일시정지, 기존→삽화 모드 전환 검사 통과. 이미지: `build/painting_mixed_0.png`, `build/painting_mixed_8.png`, `build/painting_mixed_25.png`.
- 원화 그대로 완성된 결과는 아니다. 현재 에셋은 병종당 정지 포즈이며 행군·공격은 위치·흔들림으로 표현한다. 팔다리 동작 프레임과 방향별 그림, 나무·강가의 삽화 표현, 근접 대열 간 시각적 겹침은 후속 개선 대상이다.
- 대표 병사는 실제 개별 충돌 병사를 표시하지 않는다. 실제 부대 중심·진영 위치를 바꾸지 않으며, 새 우회·관통 판정을 만들지 않았다.
- 종료 시 리소스 정리 경고가 기존 캡처 장면에서도 관찰되어, 캡처 성공과 종료 경고를 구분해서 기록한다.
