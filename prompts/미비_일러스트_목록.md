# 미비 일러스트 목록 (11/9)

토벌 적 쪽 참고: 토벌 편성이 일차별 하한(`QUEST_RABBLE_FLOOR` [2, 3, 4, 4, 4, 5, 5])으로 올라가서 **1등급 시트(01)는 지금 편성에 거의 안 나온다** —— 마지막에 그려도 된다. 자주 보이는 것은 2~5등급과 4~7등급 정예.

## (c) 새 프롬프트 사용법 (기본패 · 토벌 적)

### 공통
- 화풍은 장수 기본 초상(`prompts/등급별/1_기본`)과 같다: SD 치비 전신, 깔끔한 갈색 선, 초록 번짐 위에 선 인물, 시트 1536x1024, 칸마다 흰 번호 이름표.
- 이름표 수 = 인물 수여야 자르기가 된다. 초록색 옷은 쓰지 않게 해 두었다 (초록이 배경으로 지워진다).
- 프롬프트는 스크립트가 만든다: `python -I tools/scripts/make_troop_foe_prompts.py` (카드 이름 · 병종 · 등급은 `cards_ext.json` 에서 읽는다. 카드가 늘면 `foe_cards.py` 를 돌린 뒤 스크립트의 `FOE` 표에 한 줄을 더하고 다시 실행 —— 빠지면 멈춘다).
- 크기: 자를 때 한 변 **기본패 640px · 토벌 적 512px** 로 줄인다 (기존 장수 초상은 550~750px, 한 장 약 250KB). 토벌 적 55장은 합쳐서 약 10MB, 기본패 8장은 약 2.5MB. 더 줄이려면 `make_troop_foe_prompts.py` 의 `MAX_SIDE` 를 고치고 다시 실행.

### 기본패 병졸 (시트 2장, 2x2)
병종 차림은 `prompts/병사_스프라이트` 와 같다 (창병 = 투구 술 · 긴 창 · 작은 방패, 기병 = 말 위 · 긴 창, 궁병 = 가죽 모자 · 활 · 화살통, 도적 = 두건 · 복면 · 도 · 단검, 책사 = 검은 관 · 깃털 부채, 모사 = 짧은 망토 · 두루마리, 술사 = 뾰족 두건 · 오렌지 구슬 지팡이 · 부적, 유생 = 서책). 이름 없는 병졸이라 유명 장수 특징은 없다.

|---|---|---|
| 01 | `prompts/기본패/01_군사_4명.txt` | 1 창병 · 2 기병 · 3 궁병 · 4 도적 |
| 02 | `prompts/기본패/02_문관_4명.txt` | 1 책사 · 2 모사 · 3 술사 · 4 유생 |

### 토벌 적 (시트 11장, 5x1)
칸 순서는 모든 시트가 같다: **1 창병 · 2 기병 · 3 궁병 · 4 도적 · 5 술사**. 프롬프트 안에 7단계 사다리(누더기 농민 → 황건 민병 → 고참 → 황건 정규군 → 중무장 → 황천 귀기 → 황천 신장)가 들어 있어 시트마다 그 단계의 차림을 따른다. 흑산은 검정 · 모피, 백파는 흰색, 태평도는 노란 도포 · 부적, 황천은 잿빛 피부 · 노란 귀화로 구분한다.

### 자르기
시트를 아래 폴더에 **프롬프트 txt 와 같은 이름의 png** 로 둔다 (그린 것만 있어도 된다, 없는 시트는 건너뛴다).

```
references/기본패_시트/01_군사_4명.png, 02_문관_4명.png
references/토벌적_시트/01_1등급.png ... 11_7등급_정예.png
```

D:\Sol 에서:

```
python -I tools/scripts/slice_cards.py 기본패          # 잘림/ · 미리보기/ 에 자른다 (게임에는 아직 안 들어감)
python -I tools/scripts/slice_cards.py 기본패 --apply  # 확인한 뒤 solgukji_godot/assets/troops/ 로 복사
python -I tools/scripts/slice_cards.py 토벌적
python -I tools/scripts/slice_cards.py 토벌적 --apply  # → solgukji_godot/assets/foes/
```

한 장씩 자를 때의 명령은 `prompts/기본패/자르기_이름.txt` · `prompts/토벌적/자르기_이름.txt` 에 시트마다 적혀 있다 (`slice_sheet.py 시트.png "이름,..." 출력폴더 --hole=155 --max=...`).

## (d) 파일을 넣은 뒤 할 일

- **PC 에서 보기**: 임포트가 필요 없다. 파일을 폴더에 떨구기만 하면 게임이 다음에 카드를 그릴 때 직접 읽는다 (`DB._load_portrait`). 새 폴더(`assets/troops` · `assets/foes`)도 자동으로 만들어진다.
- **그림이 없는 카드**는 지금과 똑같이 병종 기호로 나온다 (토벌 적은 먼저 `foes/<id>` 를 찾고, 없으면 `troops/<병종>` 병졸 그림, 그것도 없으면 기호).
- **카드 · 전투 머리표 · 얼굴 메달**: 병졸 · 토벌 적은 별도 얼굴 메달 없이, 같은 그림의 위쪽 얼굴을 자동으로 잘라 쓴다 (장수 중 메달이 없는 인물과 같은 방식). 따로 그릴 것은 없다.
- **휴대폰 APK**: 빌드 전에 `solgukji_godot` 에서 `Godot --headless --path . --import` 한 번 (새 파일의 `.import` 가 생긴다). 그 `.import` 파일은 다른 그림처럼 같이 올린다.
- 어색한 칸이 있으면 해당 시트만 다시 뽑아 같은 이름으로 다시 자르면 덮어쓴다.
