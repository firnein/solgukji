## 2. 같은 진영 안에서 닮은 것 —— 구분용으로 고칠 것

**위**
- **조인:** 하후돈과 같은 덥수룩한 검은 수염이라, 조인을 **희끗한 넓은 수염**으로 바꾼다.
- **하후돈:** 수염을 **짧고 두꺼운 검은 수염**으로 줄여 조인과 나눈다.
- **장료 · 방덕 · 학소:** 셋이 같은 짧은 검은 수염이었다.
  - 장료는 각진 짧은 수염 하나만 남긴다.
  - 방덕은 덥수룩한 수염으로 바꾼다.
  - 학소는 **콧수염만** 남긴다.
- **장합과 종회:** 둘 다 긴 머리 + 비녀 + 가는 콧수염이었다.
  - 장합은 그대로 두고 **손톱 장갑**을 더한다.
  - 종회는 **높은 상투 + 금관, 수염 없음**, 위조 편지와 붓을 든다.
- **악진 · 하후패:** 둘 다 작은 소년이었다.
  - 악진은 **옅은 수염 자국 + 공성 사다리**를 단다.
  - 하후패는 **아버지의 낡은 활 + 촉의 녹색 끈**을 단다.

**오**
- **활 3명(태사자 · 정보 · 서성):**
  - 정보는 **뱀 머리 창(철척사모)**을 든다.
  - 서성은 **언월도 + 뒤에 천으로 만든 가짜 성벽**을 둔다.
- **수염 자국 3명(능통 · 정봉 · 능조):**
  - 능통은 **수염 없음**으로 바꾼다.
  - 능조는 **희끗한 짧은 수염 + 어깨에 꽂힌 화살**로 바꾼다.
- **육손:** 깃털 부채는 제갈량의 상징이다. **붉은 학자 모자 + 쌍검 + 뒤에 불타는 진영**으로 바꾼다.
- **주유:** 두 파일이 서로 달랐다(수염 없음 / 가는 콧수염). **수염 없음**으로 통일하고 **고금(거문고)**을 든다.
- **대교와 소교:** 둘 다 분홍이다. 대교를 **청록 한푸 + 접부채**로 바꾼다.

**군웅**
- **장각 · 장보 · 장량:** 셋 다 노란 두건이다.
  - 장각은 **높은 노란 도관 + 두건, 구절장, 태평요술 두루마리**.
  - 장보는 노란 두건 + 부적 검 + **종이 병사**.
  - 장량은 **노란 천을 감은 쇠투구, 창, 황건 깃발** (요술사가 아닌 무장).

## 3. 빠진 특징 보강 (선택)

**촉**
- **관우:** 녹색 전포
- **장비:** 제비턱(燕頷)
- **제갈량:** 학창의, 옥 같은 얼굴
- **강유:** 20대 후반 (지금은 20대 초)
- **간옹:** 다리를 뻗고 기대앉은 무례한 자세
- **미축:** 꼬아 올린 콧수염 대신 품위 있는 신사 + 비단옷 (정사 "雍容敦雅")
- **요화:** 쌍단검 대신 대도
- **마대:** 등 뒤로 뽑은 칼 (위연을 벤 일화)
- **사마휘:** 학처럼 마른 몸 ("松形鶴骨")

**위**
- **전위:** 등에 꽂힌 화살들
- **우금:** 비에 젖은 망토 (깃발은 창작이라 대체)
- **곽회:** 활
- **사마의:**
  - **높은 검은 관 + 검은 깃털 부채**
  - **고개를 완전히 뒤로 돌린 모습** (狼顧之相). 바둑돌은 창작이라 뺀다.
- **가후:** 반쯤 감은 눈, 문을 닫는 모습 (독약병은 창작)
- **정욱:** 아주 큰 키 ("長八尺三寸，美鬚髯")
- **조조:** 작은 키, 흑마 절영
- **순욱:** 향 연기, 빈 찬합

**오**
- **손책:** 미남, 어깨에 걸친 창
- **손권:** 큰 입, 칼로 책상을 벰
- **주태:** 맨가슴의 흉터, 긴 칼, 푸른 비단 일산
- **감녕:** 비단 돛 망토
- **정봉:** 눈 속의 맨가슴
- **노숙:** 우람한 체구 (통통함보다), 셋으로 나뉜 지도
- **황개:** 등의 곤장 자국, 불타는 배
- **마충:**
  - **갈고리 장대 + 말 걸어 넘어뜨리는 밧줄**
  - 손에 든 **붉은 말 고삐** (관우를 사로잡고 적토마를 받은 일화)
- **오범:** 바람을 읽는 깃발

**군웅**
- **여포:** 세 갈래 자금관 + 꿩깃, 붉은 비단 전포
- **동탁:** 배가 드러나는 비만
- **마등:** 거구, 큰 코, 서량 투구
- **장연:** 제비(비연) 문양
- **전풍:** 한 손목의 쇠고랑
- **관로:** 술 호리병
- **원술:** 꿀단지
