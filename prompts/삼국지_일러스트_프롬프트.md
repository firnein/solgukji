# 솔국지 장수 일러스트 생성 프롬프트

촉 시트(19명)와 같은 화풍으로 남은 66명을 만든다. 시트 하나씩 통째로 복사해 이미지 생성 도구에 넣는다.
결과물은 `python -I tools/scripts/slice_sheet.py 시트.png "이름,이름,..." 출력폴더` 로 잘라 `solgukji_godot/assets/portraits/` 에 넣는다.
**이름 순서는 시트의 읽는 순서(위 줄 왼쪽 → 오른쪽, 다음 줄…)와 같아야 한다.** 각 시트 아래 "자르기 이름 목록"을 그대로 쓰면 된다.

> 배경은 모든 시트를 촉과 같은 **연두색 종이**로 맞춘다. 자르기 스크립트가 연두 배경을 기준으로 인물을 떼어 내기 때문이다.
> 세력 구분은 옷 색으로 한다 (위 = 남색·청색, 오 = 붉은색·주황, 군웅 = 세력마다 제각각).

---

## 공통 스타일 (모든 시트 앞에 붙어 있음)

```
A character sheet of chibi Three Kingdoms (ancient China) generals, cute super-deformed proportions (about 2.5 heads tall),
full body, standing, each character facing slightly toward the viewer.
Hand-drawn ink line art with soft watercolor and colored-pencil texture, warm and detailed, consistent style across all characters.
Background: flat light green paper (#9BCF88), with a soft darker green watercolor splotch behind each character.
Below each character, a dark green brush-stroke name banner with the name in white Korean text.
Characters are arranged in a clean grid with WIDE spacing. Characters, weapons, capes and banners must NOT overlap or touch
each other or the neighboring name banners. Leave a clear gap of background between every character.
No extra text, no title, no frame, no watermark.
```

## 결과물 점검

- 인물끼리 무기나 망토가 닿았거나 이름표가 발에 붙었으면 다시 생성하는 편이 자르기에 좋다 (조금 닿는 정도는 스크립트가 떼어 낸다).
- 이름표 글자가 틀리게 나오는 일이 있다. 자를 때는 이름표 글자가 아니라 **읽는 순서**로 이름을 붙이므로, 순서만 맞으면 상관없다.
- 한 시트에서 인물 수가 프롬프트와 다르게 나오면 자르기 스크립트가 "이름표 n개 / 이름 m개" 오류를 낸다. 그때는 다시 생성한다.
