불멸 —— 이름 순서 = 이름표 번호 순서. 시트는 references/등급별_v2_시트/3_불멸/<txt 와 같은 이름>.png 로 두고 D:\Sol 에서
  python -I tools/scripts/slice_tier_v2.py 3_불멸   → 잘림/ · 미리보기/ 확인 →   python -I tools/scripts/slice_tier_v2.py 3_불멸 --apply
  다 넣으면 solgukji_godot 에서 Godot --import 한 번. (한 장씩 자를 때는 아래 명령)
먼저 기본 캐릭터(assets/portraits/<인물>.png)가 있어야 한다. 시트마다 참조 이미지를 만들어 프롬프트와 함께 붙여 넣는다.
